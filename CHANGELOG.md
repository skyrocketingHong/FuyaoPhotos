# Changelog

## 1.0.0 — 2026-09-20 (source preview)

Added a single-photo Android editor implementation: EXIF fields and manual overrides, a bottom-right frosted card, short-edge geometry, wrapping and overflow handling, original comparison and zoom preview, full-resolution JPEG/PNG export, capture-tag allowlisting and private runtime font imports.

Followed FuyaoColorPicker's layering, bilingual documentation, four variants, shared run configurations and signing template. Release artifacts remain unsigned without a private configuration instead of falling back to a debug key.

53 offline core checks and syntax/resource checks passed. Android builds and device validation remain pending. No APK, macOS font binary or original reference screenshot is included.
